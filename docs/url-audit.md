# URL accuracy audit

Generated by `python3 scripts/audit_urls.py --check-age` on 2026-09-19. Regenerate
after fixing entries; the GitHub lookups are cached in `.cache/` (git-ignored).

Most tool URLs in this list were found by automated search when the older events
were imported, and some matched the wrong project. This report lists the ones
worth a human look, grouped by why they were flagged:

- **created more than a year after the event** — the strongest signal of a wrong
  match (a 2016 talk can't have been about a repo created in 2024), though some
  are legitimate late publications or re-uploads.
- **repo name shares no word with the tool name** — may be a codename; check.
- **user/org page** — the URL is a profile, not a repo; find the actual repo if one exists.
- **repo not found (404)** — dead; find the new location or clear the URL.

To fix one: edit the `Github URL` in the file, run `python3 scripts/validate.py`
and `python3 AutoReadme.py`, and open a PR. Use the "Fix a broken or wrong link"
issue template if you'd rather report than fix.
