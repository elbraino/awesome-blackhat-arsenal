## 🤖 AI, ML & Data Science
<details><summary><strong>Who is my Bodyguard? Demystifying Enterprise Security Rules with an AI Agent</strong> — Jordan Garzon, Victor Arango</summary>

**Track:** AI, ML & Data Science · **Event:** Canada 2026  
🔗 **Link:** [https://github.com/intuit/bodyguard](https://github.com/intuit/bodyguard)  
📝 **Description:** Bodyguard is a local, Dockerized RAG agent that ingests security code (SQL detection rules, Python logic) and documentation (Markdown, Confluence), then answers plain-language questions about what the deployed defenses actually do. Every answer cites its source file, exposing drift between documentation and code, and it can optionally run live BigQuery queries to show real examples.
