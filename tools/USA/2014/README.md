📝 **Description:** With the widespread adoption of DEP, code-reuse techniques such as ROP are essential parts of current exploits. ASLR randomizes the code layout to make ROP harder; unfortunately, ASLR-bypasses abound. The Immunant compiler delivers improved hardening against ROP attacks.
